\caption{%
  \textbf{System model.} An iOS client uses the Secure Enclave to produce App Attest
  evidence (enrollment attestation~(1), per-request assertions bound to a request
  hash~(2)) and DeviceCheck tokens~(3); the developer backend verifies this evidence
  and serves the protected resource only if verification succeeds~(4), querying
  Apple server-to-server for DeviceCheck state~(3a). Apple's infrastructure and the
  Secure Enclave form the trusted computing base; the client's software and the
  network are adversary-controlled (C1--C4). Security collapses to a single
  server-side \emph{enforcement decision}: when it is incomplete or absent
  (failure classes F1--F8), the primitives provide no protection even though the
  client appears to adopt them.%
  \label{fig:system-model}}

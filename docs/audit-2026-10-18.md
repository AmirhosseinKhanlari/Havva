# Havva platform audit (2026-10-18)

Whole-project correctness/security audit. Baseline: 110/110 tests passed, yet the
measurement logic below was wrong by construction; the suite did not exercise it.
Each item was verified in code or reproduced unless marked *(agent-reported)*.
Status: ALL items in Tiers 1-3 were addressed on 2026-10-18 (276/276 tests pass, from 110).
Not yet validated on-device (logic is unit-tested, device runs still required before use for
paper results): the rebuilt enforcement probe (persistent Frida arm + no-relaunch re-drive),
EntitlementShim scene-delegate net, EvasionKit header/slide remap, device liveness tri-state.

## Tier 2: high
- Path traversal to `rmtree` via form `dylibs` -> `label` -> `work_dir/inst_{app}_{config}` (dynamic.py:402, instrument.py:257).
- Reflected XSS: `_job_status.html` renders query `reload` with `|safe` in JS.
- Forgeable auth when `WEB_AUTH_TOKEN` unset (`auth.py` fallback secret), bound to 0.0.0.0.
- Cancel pkills device helpers for any running job (no device-job tracking); kills manual idevicesyslog.
- Autoremove `grep -qa "$BID"` unanchored regex -> can `rm -rf` the wrong app (acquire.py).
- Acquisition row clobbered by older-version acquire; bundle-id acquire duplicates `apps` rows (reproduced in DB).
- Crash reports attributed by bundle-suffix substring (device.py) -> false TAMPER_DETECTED, bypass run skipped.
- `is_app_running` False on transient failure -> false "exited"; `pid_running` tri-state unused.
- Bypass-run crash -> NOT_PINNED (dynamic.py); stale HAR reused on export failure (capture.py).
- Static tab 500s with >=2 CVE deps (Jinja sort on list of dicts).
- ConnectionTraces are the Mac->server leg, no client attribution; `state:failed` ignored; `unresolved` unreachable.
- iap_bypass: `verify=False`; filter drops itunes/amazon/google, includes auth/token; verdict coerced to True on truncation; prompt-injectable.

## Tier 3: medium
- util: `run_cmd_streamed` drops CRLF + final line; `run_cmd` discards output on timeout (precedence).
- acquire: `"404"` in `_PERMANENT` matches UUIDs; stale enc.ipa accepted; `sync_ipadecrypt_host` clobbers user/port.
- otp: keyword path returns years; only newest message examined.
- EvasionKit hides pre-alias names only; header/slide not remapped; sysctl OOB write.
- EntitlementShim: UIScene launches unwrapped; selector-only fallback; registry overflow -> no-op; inherited clobber.
- device: `_tap_label` substring taps negations/SSO; login consumes window; `_login_phone` never "success"; no stop_check from run_config.
- web: log cross-talk; EventSource leak; .env injection via settings; secrets on argv; cancel-after-complete shows cancelled.
- data: apps rank/country overwritten; iap.py 404 -> has_iap=0 forever; storage_scan aborts on encrypted DB; ats_runtime unreachable->justified; cve repo mapping + fabricated CVE id.

## Improvements adopted
Baseline-derived enforcement oracle; .ips JSON parsing; per-app traffic attribution (baseline differential); unified evidence blob; separate App Attest / DeviceCheck confidence; scoped cancel; tri-state liveness; tests for measurement logic.

›ATS declared-vs-needed gap {% if a['ats_gap'] and a['ats_gap'].get('checked') %}({{ a['ats_gap']['verdict']|replace('_',' ') }}){% endif %}
Runs nscurl --ats-diagnostics against each endpoint to see whether it already meets Apple's default ATS. Weakening ATS for an endpoint that passes anyway is unnecessary (MASTG-TECH-0149).
What the result means
Default ATS = TLS 1.2+ · forward secrecy (ECDHE) · valid modern cert (SHA-256, RSA-2048/ECC-256, trusted). For public endpoints this is a low bar most already clear.
pass: meets default ATS, so any weakening for it was unnecessary. fail: does not meet it (legacy TLS / weak cipher / cert issue), so an exception is justified (and the endpoint itself is weak). ?: unreachable at check time; no verdict.
Measures the server's TLS posture only, not certificate pinning. A “pass” server can still be MITM'd if the app does not pin.
